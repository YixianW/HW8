# Reflection

## 1. How far did the agent get?
The agent finished most of the main parts on the first try. It created the basic structure of the project, including account creation, login, quiz flow, score history, and question feedback. The program could run, and I was able to test the main features. So overall, the agent got pretty far in the first build.

## 2. Where did I intervene?
I did not write the code from zero, I wrote the spec first, chose the quiz theme, and decided the question categories and sample questions. After the agent built the project, I tested it myself and checked whether the main functions worked. Later, I used the review results to guide the next fixes. I think some of the problems could have been reduced if my spec had been more clear about saved data and error handling.

## 3. How useful was the AI review?
the review found some deeper problems. For example, the app could crash if the .dat files had bad or broken data.

## 4. What would I change about my spec?
If I did this again, I would make the spec more clear about saved data structure and error handling.

## 5. When would I use this workflow again?
I think this workflow is good for small projects with clear goals. It works best when I already know what features I want and the AI can follow the spec step by step. It is less good for bigger projects or messy projects where the requirements keep changing. It is also not the best choice when the work needs a lot of personal judgment or more creative decisions.
